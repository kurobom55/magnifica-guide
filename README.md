# マグニフィカS お助け帳（非公式）

デロンギ 全自動コーヒーマシン マグニフィカS（ECAM22112）の、ランプの意味・困ったときの対処・お手入れ手順を、スマホで見やすくまとめた個人用のページです。

- ランプ：別紙クイックガイドの組み合わせ表示を、絵で見比べて調べられます
- 困った：症状から原因と直し方を探せます
- お手入れ：石灰除去・抽出ユニット・挽き目の調整などを、図つきで1ステップずつ案内します
- AIに聞く：この機械の資料つきの質問文をコピーし、お使いのAIアプリに貼って質問できます
